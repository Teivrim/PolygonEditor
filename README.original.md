## Сборка

```
cmake -B build && cmake --build build
```

- **Проверка:** ⚠️ Сборка **не проверялась** на этой машине. Проверь перед публикацией.

## Что внутри

- Импорт FBX/OBJ/DAE через Assimp
- Два рендер-бэкенда: Win32/GDI+ для UI и GLFW/OpenGL для сцены
- Панели редактора, камера, ввод, lifecycle приложения
- Заголовочные библиотеки вендорёны локально — сборка без сети
- План развития на 15 версий: ECS, JSON-сцены, префабы, тени, Lua

## Кому подойдёт

Студентам и инди, изучающим, как устроен 3D-движок изнутри

## Чем отличается от аналогов

Учебный движок с открытым планом развития — видно, куда ведёт архитектура.

## Требования

- CMake 3.20+, Ninja или Make
- Компилятор с поддержкой C++17
- Git и сеть — для первого запуска CMake (FetchContent тянет зависимости)
